Jeder Gegner entscheidet sich im Voraus, welchen Skill er auf welches Ziel einsetzt, und das wird angezeigt. In seinem Zug führt er genau diesen Plan aus, statt zufällig zu wählen.

      Umsetzung

      1. Plan am Monster speichern (mon.gd):
      gdscript
      # Geplanter Zug eines Gegners: {"skill": Dictionary, "target": Monster}, leer = noch nicht geplant
      var _intent: Dictionary = {}

      2. Planen statt würfeln (battle.gd), den Zufall aus _ki_turn herauslösen:
      gdscript
      ## Gegner legt seinen nächsten Zug fest (wird angezeigt, bevor er dran ist)
      func _plan_intent(emon: Monster) -> void:
              var usable = emon._skills.filter(func(skill): return Skills.is_playable(emon, skill))
              if usable.is_empty() or _opponents_of(emon).is_empty():
                      emon._intent = {}
                      return
              var skill = usable.pick_random()
              var side = _allies_of(emon) if Skills.targets_friends(skill) else _opponents_of(emon)
              emon._intent = {"skill": skill, "target": side.pick_random()}
              Events.monster_intent_changed.emit(emon)

      func _ki_turn(emon: Monster) -> void:
              if not emon.is_alive():
                      return
              var intent = emon._intent
              # Ziel inzwischen K.O. oder Skill nicht mehr spielbar: neu planen
              if intent.is_empty() or not intent.target.is_alive() or not Skills.is_playable(emon, intent.skill):
                      _plan_intent(emon)
                      intent = emon._intent
              if intent.is_empty():
                      return
              _use_skill(emon, intent.skill, intent.target)
              intent.skill.scouted = true
              # direkt den nächsten Zug planen, damit der Spieler reagieren kann
              _plan_intent(emon)

      3. Zeitpunkt: In _ready() nach reset_battle_state() für alle Gegner einmal _plan_intent aufrufen. Wenn ein eigenes Monster K.O. geht oder gefangen wird (_check_game_over), alle Gegner neu planen, deren Ziel weg ist.

      4. Anzeige (neues Signal monster_intent_changed in events.gd, Darstellung in monster_scene.gd):
      - Über dem Gegner ein kleines Symbol mit Text, je nach Art des Skills:
        - Angriff: Schwert, Skillname und geschätzter Schaden, berechnet mit Skills.calc_damage(emon, target, skill) (bei Flächen-Skills pro Ziel)
        - Schild: Schild-Symbol und Wert
        - Buff: Pfeil nach oben und betroffener Wert
      - Am Ziel eine Markierung, zum Beispiel ein rot pulsierender Rahmen oder ein kleines Gegner-Portrait mit dem Zielsymbol. Der rote Rahmen ist für Angriffe, ein grüner oder blauer für Schild und Buff auf einen Verbündeten. Mehrere Gegner auf demselben Ziel ergeben
        gestapelte Portraits, damit man sieht: „Monster A bekommt 2 Angriffe ab“.
      - Optional im Initiative-Rad beim Portrait des Gegners ein Mini-Symbol der Absicht, dann sieht man auch die Reihenfolge.

      5. Bonus, der sofort Tiefe bringt: Die Schadensschätzung sollte Schilde einrechnen („12 → 4 nach Schild“). So sieht man direkt, dass sich Blocken lohnt.

      Folge für das Balancing

      Mit sichtbaren Absichten werden die Basis-Blocks deutlich wertvoller, aber nur, wenn sie mitskalieren. Darum würde ich gleichzeitig add_flat_shield auf einen Prozentwert der Verteidigung umstellen, wie es die anderen Schild-Skills schon machen.
